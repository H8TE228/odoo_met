# odoo_met

Кастомные модули Odoo 19 для автоматизации работы менеджера по закупкам.
Учебный проект по ролям производственного предприятия (ООО ПромДеталь).

## Технологический стек

- Odoo 19
- PostgreSQL 15
- Docker / Docker Compose

## Быстрый запуск

```bash
git clone https://github.com/H8TE228/odoo_met.git
cd odoo_met
docker-compose up -d
```

Затем открыть в браузере: http://localhost:8069 и создать базу данных
(мастер-пароль для создания базы указан в config/odoo.conf).

Кастомные модули лежат в папке addons (примонтирована в контейнер как
/mnt/extra-addons). Режим разработчика включён через dev_mode=all,xml
в config/odoo.conf.

## Модуль: supplier_price_book

Расширяет стандартные модули "Закупки" и "Склад" под задачи менеджера
по закупкам. Реализовано по принципу наследования стандартных моделей
Odoo (_inherit), без создания дублирующего функционала.

### US №3: Базовый справочник цен поставщиков

Статус: готово.

- Цены поставщиков хранятся в стандартном справочнике поставщиков
  (product.supplierinfo) в карточке товара, вкладка "Покупка".
- В карточку товара добавлены вычисляемые поля "Самый дешёвый поставщик"
  и "Мин. цена закупки" (блок "Лучшая цена закупки"), которые
  автоматически пересчитываются при изменении цен.
- При создании заказа поставщику цена за единицу подтягивается
  автоматически из справочника (стандартный механизм Odoo).

Реализация: models/product_template.py (вычисляемые поля),
views/product_template_views.xml (отображение в карточке товара).

### US №4: Корректировка условий поставки в заказе (сроки и объёмы)

Статус: готово.

- На подтверждённом заказе поставщику остаются редактируемыми поля
  "Ожидаемая дата прихода" и "Количество" (стандартное поведение Odoo).
- Добавлена кнопка "Обновить график" в шапке заказа, доступная только
  для подтверждённого заказа.
- По нажатию кнопки в чат заказа публикуется уведомление о новом
  ожидаемом сроке прихода сырья (в часовом поясе пользователя).

Реализация: models/purchase_order.py (метод action_update_schedule),
views/purchase_order_views.xml (кнопка в форме заказа).

## Структура модуля

```
addons/supplier_price_book/
   __init__.py
   __manifest__.py
   models/
      __init__.py
      product_template.py        # US №3: вычисляемые поля
      purchase_order.py          # US №4: кнопка "Обновить график"
   views/
      product_template_views.xml # US №3: карточка товара
      purchase_order_views.xml   # US №4: форма заказа
```

## Установка и обновление модуля

Установить (первый раз) или обновить после правок:

```bash
docker-compose run --rm web odoo -d ИМЯ_БАЗЫ -u supplier_price_book --stop-after-init
docker-compose restart web
```

Правки только в XML подхватываются перезагрузкой страницы (dev_mode=xml);
изменения в моделях Python требуют обновления модуля и перезапуска web.
