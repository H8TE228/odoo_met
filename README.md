# odoo_met

Кастомные модули Odoo 19 для автоматизации работы менеджера по закупкам.
Учебный проект по ролям производственного предприятия (ООО ПромДеталь).

## Технологический стек

- Odoo 19
- PostgreSQL 15
- Docker / Docker Compose

## Быстрый запуск

```bash
git clone https://github.com/H8TE228/odoo_met.git
cd odoo_met
docker-compose up -d
```

Затем открыть в браузере: http://localhost:8069 и создать базу данных
(мастер-пароль для создания базы указан в config/odoo.conf).

Кастомные модули лежат в папке addons (примонтирована в контейнер как
/mnt/extra-addons). Режим разработчика включён через dev_mode=all,xml
в config/odoo.conf.

## Модуль: supplier_price_book

Расширяет стандартные модули "Закупки", "Склад" и "Производство" под задачи
менеджера по закупкам. Реализовано по принципу наследования стандартных
моделей Odoo (_inherit) плюс одна собственная модель для экрана дефицита.

### US №3: Базовый справочник цен поставщиков

Статус: готово.

- Цены поставщиков хранятся в стандартном справочнике (product.supplierinfo)
  в карточке товара, вкладка "Покупка".
- В карточку товара добавлены вычисляемые поля "Самый дешёвый поставщик"
  и "Мин. цена закупки", пересчитываются автоматически.
- При создании заказа поставщику цена подтягивается автоматически.

Файлы: models/product_template.py, views/product_template_views.xml.

### US №4: Корректировка условий поставки (сроки и объёмы)

Статус: готово.

- На подтверждённом заказе редактируются дата прихода и количество.
- Кнопка "Обновить график" публикует в чат заказа уведомление о новом сроке
  (в часовом поясе пользователя).

Файлы: models/purchase_order.py (action_update_schedule),
views/purchase_order_views.xml.

### US №1: Ручной заказ сырья по списку дефицита

Статус: готово.

- Экран "Дефицит сырья" (меню приложения Покупка) с колонками: материал,
  текущий остаток, необходимый объём, к заказу.
- Потребность рассчитывается по открытым производственным заказам (mrp),
  дефицит пересчитывается автоматически при открытии экрана.
- Кнопка "Заказать" создаёт черновик заказа поставщику с самым дешёвым
  поставщиком из справочника US №3.

Файлы: models/raw_material_shortage.py, security/ir.model.access.csv,
views/raw_material_shortage_views.xml.

### US №5: Оформление возврата некондиционного сырья поставщику

Статус: готово.

- Кнопка "Оформить возврат" на заказе запускает стандартный мастер возврата
  (stock.return.picking) по подтверждённому приходу.
- После возврата экран дефицита пересобирается заново (связь с US №1).
- Финансовая часть (кредит-нота) остаётся за модулем Учёт.

Файлы: models/purchase_order.py (action_create_return),
views/purchase_order_views.xml.

## Структура модуля

```
addons/supplier_price_book/
   __init__.py
   __manifest__.py
   models/
      __init__.py
      product_template.py         # US №3
      purchase_order.py           # US №4, US №5
      raw_material_shortage.py    # US №1
   security/
      ir.model.access.csv         # права на модель дефицита
   views/
      product_template_views.xml
      purchase_order_views.xml
      raw_material_shortage_views.xml
```

## Установка и обновление модуля

```bash
docker-compose run --rm web odoo -d ИМЯ_БАЗЫ -u supplier_price_book --stop-after-init
docker-compose restart web
```

Правки только в XML подхватываются перезагрузкой страницы (dev_mode=xml);
изменения в моделях Python требуют обновления модуля и перезапуска web.
